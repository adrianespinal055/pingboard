# PingBoard

[![CI](https://github.com/adrianespinal055/pingboard/actions/workflows/ci.yml/badge.svg)](https://github.com/adrianespinal055/pingboard/actions/workflows/ci.yml)

PingBoard is a self-hosted uptime monitor: it checks your websites every minute, stores response times and alerts you on Discord when something goes down.

🚧 Work in progress.
